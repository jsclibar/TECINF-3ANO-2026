# Levantamento de Requisitos

## Informações do Cliente

**Instituição:** Escola Horizonte

## Situação Atual

A Escola Horizonte realiza o controle das informações dos alunos por meio de planilhas do Microsoft Excel. Apesar de atender às necessidades básicas, esse método dificulta a organização dos dados, a realização de consultas e a atualização das informações, além de não fornecer um controle preciso da quantidade de alunos ativos e inativos.

Atualmente, a instituição estima possuir aproximadamente **1.500 alunos ativos**, porém esse número não pode ser confirmado com exatidão.

## Objetivo

Desenvolver um sistema para centralizar e organizar o cadastro dos alunos, proporcionando maior confiabilidade, agilidade e facilidade no gerenciamento das informações.

## Requisitos Funcionais

### RF01 – Cadastro de Alunos

O sistema deverá permitir o cadastro das seguintes informações de cada aluno:

- Nome
- Idade
- Sexo
- Endereço
- Telefone
- Data de inscrição no curso
- Valor pago pelo curso

### RF02 – Gerenciamento de Dados

O sistema deverá permitir:

- Armazenar os dados dos alunos.
- Consultar informações dos alunos.
- Alterar informações cadastrais.
- Excluir registros de alunos.

## Premissas

- Cada aluno deverá possuir um cadastro único no sistema.
- O sistema deverá organizar os dados de forma estruturada para facilitar consultas e atualizações.
- O sistema deverá permitir o gerenciamento das informações dos alunos de forma simples e intuitiva.
