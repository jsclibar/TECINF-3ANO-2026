# Levantamento de Requisitos

## Informações do Cliente

**Empresa:** TecHelp Assistência Técnica

---

## Situação Atual

A TecHelp é uma assistência técnica especializada na manutenção de computadores, notebooks e celulares.

Atualmente, todas as informações dos equipamentos recebidos são registradas em um caderno. Esse método dificulta localizar atendimentos anteriores, acompanhar os serviços em andamento e atualizar informações dos clientes.

A empresa recebe, em média, **80 equipamentos por mês** e deseja informatizar esse processo.

---

## Objetivo

Desenvolver um sistema para organizar os atendimentos realizados pela assistência técnica, permitindo cadastrar, consultar, alterar e excluir informações de forma rápida e confiável.

---

## Requisitos Funcionais

O sistema deverá permitir registrar as seguintes informações:

- Nome do cliente;
- Telefone para contato;
- Tipo do equipamento;
- Marca;
- Modelo;
- Número de série;
- Defeito informado pelo cliente;
- Data de entrada;
- Valor do orçamento;
- Situação do atendimento.

Além disso, o sistema deverá permitir:

- Cadastrar novos atendimentos;
- Consultar informações cadastradas;
- Alterar informações;
- Excluir registros.

---

# Atividades

## Parte 1 – Modelagem Conceitual

Com base no cenário apresentado, elabore a modelagem conceitual identificando:

- A entidade;
- Os atributos da entidade.

---

## Parte 2 – Modelagem Lógica

Transforme a modelagem conceitual em uma tabela.

Defina:

- Nome dos campos;
- Tipo de dado de cada campo;
- Tamanho dos campos quando necessário;
- Qual campo será utilizado para identificar cada registro.

---

## Parte 3 – Modelagem Física

Implemente a estrutura criada utilizando SQL.

O script deverá:

- Criar o banco de dados;
- Selecionar o banco criado;
- Criar a tabela;
- Permitir que o script seja executado mais de uma vez sem apresentar erros.

---

## Parte 4 – Inserção de Dados

Cadastre pelo menos **7 atendimentos** diferentes.

Procure variar:

- Nome dos clientes;
- Tipo de equipamento;
- Marca;
- Modelo;
- Datas de entrada;
- Valores de orçamento;
- Situação do atendimento.

---

## Parte 5 – Alteração de Dados

Escreva comandos SQL para:

- Alterar o telefone de um cliente;
- Alterar o valor do orçamento de um atendimento;
- Alterar a situação de um atendimento;
- Alterar mais de uma informação de um mesmo registro utilizando um único comando.

---

## Parte 6 – Exclusão de Dados

Escreva comandos SQL para:

- Excluir um atendimento específico;
- Excluir mais de um atendimento utilizando uma única instrução;
- Excluir todos os atendimentos de uma determinada situação.

Antes de executar cada comando de exclusão, utilize uma consulta para verificar quais registros serão afetados.

---

## Parte 7 – Consultas

Escreva consultas SQL para:

1. Listar todos os atendimentos;
2. Exibir apenas o nome do cliente e a situação do atendimento;
3. Listar apenas os equipamentos de uma determinada marca;
4. Listar os atendimentos com orçamento superior a R$ 500,00;
5. Listar os atendimentos realizados após uma determinada data;
6. Listar os atendimentos em ordem alfabética pelo nome do cliente;
7. Listar os atendimentos ordenados do maior para o menor valor do orçamento.

---

# Entrega da Atividade

A atividade deverá ser realizada **em duplas**.

Cada dupla deverá entregar os seguintes arquivos:

## Arquivo 1 – Modelagem

Arquivos do **brModelo** contendo:

- Modelagem conceitual;
- Modelagem lógica.

---

## Arquivo 2 – Script SQL

Um único arquivo chamado **atividade.sql** contendo todas as etapas da implementação.

O arquivo deverá estar organizado em seções, utilizando comentários para facilitar a leitura.

Exemplo:

```sql
-- =====================================================
-- CRIAÇÃO DO BANCO DE DADOS
-- =====================================================

CREATE DATABASE ...

USE ...

CREATE TABLE ...

-- =====================================================
-- INSERÇÃO DOS DADOS
-- =====================================================

INSERT ...

-- =====================================================
-- ALTERAÇÃO DOS DADOS
-- =====================================================

UPDATE ...

-- =====================================================
-- EXCLUSÃO DOS DADOS
-- =====================================================

DELETE ...

-- =====================================================
-- CONSULTAS
-- =====================================================

SELECT ...
```

O script deverá conter:

- Criação do banco de dados;
- Criação da tabela;
- Inserção dos registros solicitados;
- Comandos de alteração (`UPDATE`);
- Comandos de exclusão (`DELETE`);
- Todas as consultas (`SELECT`) solicitadas na atividade.

O script deverá executar corretamente do início ao fim em um banco de dados vazio.

---

## Critérios de Avaliação

Serão considerados:

- Correta identificação da entidade e dos atributos;
- Qualidade da modelagem conceitual e lógica;
- Escolha adequada dos tipos de dados;
- Organização e clareza do código SQL;
- Funcionamento dos comandos SQL desenvolvidos;
- Atendimento aos requisitos propostos no estudo de caso.
